v2all

Dead configs
stay out.

Public config lists in. One subscription out.
If it can't proxy traffic, it doesn't make the cut.

Add as a subscription in v2rayNG, Hiddify, or v2rayN.

The filter

An open port
isn't proof.

22 auto-updated sources. About 10,000 links scanned. Only configs that complete a real Xray handshake survive.

  1. 01

    Collect

    Fetch the public lists. Remove duplicates and non-routable IPs.

  2. 02

    Connect

    TCP-check each host and port. Reachable isn't the same as working.

  3. 03

    Prove it

    Start Xray. Fetch a URL through the proxy. No traffic, no subscription.

  4. 04

    Publish

    Normalize the surviving links. Rebuild the subscription every 6 hours in CI.

The catch

CI isn't your network.

A CI handshake isn't a test of your network. Public servers can disappear. Refresh the subscription if a connection fails. These are third-party proxies; don't use them for sensitive traffic.

$ ./v2all.py --pool 300 --top 30
